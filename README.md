# Car Sharing Cost Splitter — Copilot live demo

Een demo-repo om te laten zien hoe de **GitHub Copilot app** werkt:
één prompt → sub-sessies (parallelle agents) → issues → pull requests → een werkende website.

Doel-app: een eerlijke **autokosten-verdeler** tussen twee mensen
(brandstof naar rato van gereden km, overige kosten 50/50).

> Deze repo wordt live opgebouwd tijdens de demo.
