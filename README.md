# Car Sharing Cost Splitter

Een eerlijke **autokosten-verdeler** voor twee mensen die één auto delen (Justin & Milan).

- **Brandstof** wordt verdeeld naar rato van gereden kilometers per persoon.
- **Overige kosten** (wasstraat, onderhoud, …) worden 50/50 gedeeld.
- **Live saldo** en een duidelijke afrekening: *wie betaalt wie*.

## Gebruiken
Open simpelweg **`index.html`** in je browser. Geen build, geen dependencies.

## Schermen
- **Overzicht** — saldo per persoon + ritten/tankbeurten/kosten toevoegen
- **Afrekening** — wie betaalt wie, met de volledige berekening
- **Historie** — alle invoer, met verwijderen
