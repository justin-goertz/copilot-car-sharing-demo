GitHub Copilot app

De agent-native desktop-ervaring.

Copilot app · wat is het?

Eén plek om je agents aan te sturen

  • Een losstaande desktop-app — geen plug-in in je editor.
  • In één overzicht (My Work) zie je al je sessies, issues, pull requests en automations.
  • Elke sessie draait in een eigen, afgeschermde kopie van je code (git worktree).
  • Beschikbaar voor Copilot Business en Enterprise.

Copilot app · wat kun je ermee?

De mogelijkheden

Agents parallel

Meerdere sessies tegelijk: bug fixen, feature bouwen én PR-feedback verwerken.

Drie modi

Interactive (samen), Plan (jij keurt goed), Autopilot (zelfstandig).

Canvases

Plan, pull request, browser, terminal of dashboard — meekijken en bijsturen.

Sandboxes

Lokaal of in de cloud — afgeschermd en met enterprise-policy.

Agent Merge

Bewaakt CI, volgt reviewers, fixt checks en merge't als jouw voorwaarden kloppen.

Van issue tot merge

Start vanuit een issue of prompt → plan → code → pull request → merge.

Copilot app · wat levert het op?

Waarde voor developers én de business

Voor developers

In je flow blijven

  • Niet meer springen tussen editor, terminal en browser
  • Routineklussen uitbesteden; zelf de lastige dingen doen
  • Altijd zien wat de agent deed en controleerde
Voor de business

Meer grip, sneller resultaat

  • Zet een hele groep agents in vanuit één plek
  • Grip via sandboxes, policy en een duidelijk spoor
  • Van prompt tot merge, met Agent Merge erbij
"Onze engineers sturen een hele groep agents aan en runnen meerdere projecten tegelijk — allemaal vanaf één plek." — David Jobling, Avanade

Project HydraFusion

Topkwaliteit door meerdere modellen slim te combineren.

HydraFusion · wat is het?

Een slimme regelaar die modellen combineert

  • Je kiest 'HydraFusion' als model — het maakt zelf een aanpak per taak.
  • Het combineert meerdere modellen van verschillende aanbieders in één keer.
  • Het pakt de eenvoudigste aanpak die de kwaliteit tóch haalt.
  • Anders dan Auto (dat één model kiest): HydraFusion kiest een héle werkwijze.
HydraFusion-architectuur. Beeld: github.blog

HydraFusion · hoe het werkt & wat het oplevert

Drie werkwijzen — automatisch gekozen

Single
Eén model lost het meteen op. Snel en zuinig.
Cascade
Goedkoop model eerst; niet goed genoeg → door naar een sterker model.
Critique
Eén model maakt het, een ander checkt het, het eerste verbetert het.
+4,9 ppthogere taakkwaliteit
67% lagere kosten per taak
…en jij hoeft geen model meer te kiezen.
